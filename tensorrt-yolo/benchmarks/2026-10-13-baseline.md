# 2026-10-13 常驻 Runner 首轮基线

Release / GCC 9.4.0 / aarch64 / CUDA toolkit 11.4.315 / OpenCV 4.5.4。
Jetson Linux R35.4.1，kernel 5.10.120-tegra。

FP16、FP32 串行运行，均 50 warmup + 200 iterations，使用 test.jpg。
本轮测量期间未启动本任务的其他 GPU 验证。未锁定时钟、未改变功耗模式，未采集温度和频率时序，也未核实系统其他进程负载；不能视为受控硬件性能上限。
`nvpmodel -q` 返回 MODE_50W (3)，但同时报告部分 sysfs 路径不存在/权限错误，因此该查询仅作部分环境记录。
本报告保存的是排除本任务可视化可能重叠后重新串行测量的一轮结果。

两种 engine 都通过旧版 raw baseline 逐字节回归：同一 Runner 连续 5 次，计时开/关交替。两次 benchmark 的最终 raw 输出均与其本进程计时前参考输出一致。
预处理与冻结 input.bin 逐字节一致；C++ CPU 测试及 7 项 Python 回归均通过。
